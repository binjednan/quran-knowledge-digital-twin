# التوأم المعرفي الرقمي للقرآن الكريم

الإصدار الدلالي الثاني: ملف تفاعلي مستقل مبني على النص المرفق وحده،مع النصوص والشواهد والسياقات ودرجات اليقين والأسئلة غير المحسومة. لم تستخدم تفاسير أو معاجم أو مصادر دينية أو تاريخية خارج النص.

- [تشغيل التوأم المعرفي بالتصميم المحدث](https://binjednan.github.io/quran-knowledge-digital-twin/?v=444b7136#home). الواجهة العربية تجمع مسارات القراءة والمقارنة والاستكشاف، مع تنقل سريع على الهاتف، ومظهرين فاتح وداكن.
- [فتح شبكة أسماء الأعلام](https://binjednan.github.io/quran-knowledge-digital-twin/?v=444b7136#names). ابدأ بمقارنة الأعداد، ثم افتح خريطة الجوار أو المصفوفة. تفتح العروض الثلاثة شواهد الزوج في النطاق نفسه.
- [قرارات تصميم الواجهة ومصادرها](https://binjednan.github.io/quran-knowledge-digital-twin/?v=444b7136#method). يربط [سجل البحث](ui-design-research.json) قرارات العرض بإرشادات التصميم ودراسات ومراجعات المستخدمين وحدودها. البيانات التحليلية من النص المرفق وحده.
- [تنزيل ملف HTML المحدث](index.html) للعمل دون اتصال. قد يعرض GitHub زر التنزيل بسبب حجم الملف.
- [تنزيل الحزمة الكاملة للواجهة المؤرشفة](quran-semantic-twin.zip). تضم إصدار HTML سابقًا والقراءات والدراسات والمنظومات وقواعد البيانات وسجلات المراجعة وأدوات إعادة البناء.
- [النص الأصلي](quran-uthmani-numbered-ayahs.json): محفوظ دون تغيير.

## النطاق المنجز

- 114 سورة و6236 آية وفق ترقيم المرفق،ضمن 643 مقطع قراءة مكتوب ومراجع.
- 88 دراسة مقارنة لبوابات البحث،و16 توليفاً للمنظومات المطلوبة.
- 3150 سجل علاقة بشواهده وصوته وقيده،مع فصل الإثبات والنفي والقول والشرط والسؤال والتشبيه.
- خرائط شبكية محلية وعامة،وشجرات مكونات وجسور بين المنظومات،ومصفوفة وخرائط كثافة وتدفق وفهرس لفظي كامل.
- تنقل من المرجع إلى النص والسياق والقراءة والدراسة والشبكة،مع تصدير SQLite وGraphML وJSON داخل الحزمة.

المراجعة مستقلة بين مسارات التحليل الآلية،بسجلات اعتراضات وتصحيحات وبصمات مطابقة للمحتوى. لا تمثل مراجعة بشرية متخصصة أو اعتماد المستخدم. خضعت الواجهة المحدثة لفحوص التفاعل وإعادة تدفق الصفحات وعينات التباين في Chrome. فُحصت أحجام الهاتف بالمحاكاة. تجارب المستخدمين المذكورة في سجل البحث أجريت على أعمال أخرى.

## حدود الاستنتاج

تغطية الآيات لا تعني استنفاد كل معنى أو كل علاقة ممكنة. الدراسات الثماني والثمانون نطاقات بحث معلنة،وليست معجماً جذرياً كاملاً لكل ألفاظ القرآن. النتائج البحثية قابلة للنقد من شواهدها؛الأسئلة والبدائل ظاهرة داخل الملف. درجات اليقين وصفية وليست نسباً احتمالية.

اشتراك الرسم أو الجذر المفترض لا يثبت وحدة المعنى،والتلازم والدرجة الشبكية لا يثبتان السببية أو الأهمية القيمية. تسميات المنظومات عدسات تنظيمية من طلب المستخدم،والأحداث معروضة بترتيب النص دون تواريخ مستوردة. شاشات الإصدار الأول محفوظة في الأداة للمقارنة وموسومة بحالتها السابقة،وسجل Git يحتفظ بالملف المنشور الأول.

بيانات ناشر المرفق ومكانه وتاريخه محفوظة للإسناد ولا تدخل الاستدلال. يبقى تنبيه المرفق بشأن افتتاح95:1 و97:1 ظاهراً دون تعديل النص.

مصدر النص بحسب المرفق: [Tanzil Project](https://tanzil.net)،والحقوق الواردة محفوظة في [NOTICE.txt](NOTICE.txt) وفي البيانات والأداة. البصمات الكاملة في [SHA256SUMS](SHA256SUMS).
