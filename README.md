# التوأم المعرفي الرقمي للقرآن الكريم

ملف تفاعلي مستقل لاستكشاف النص المرفق: البحث في الآيات والألفاظ، وشبكات التلازم، والمفاهيم المرشحة، والشواهد والسياقات، والمصفوفات وخرائط الكثافة والتدفق.

**حالة النسخة المنشورة:** اكتملت فهرسة الملف وحساب شبكته وفق القواعد المعلنة. تتضمن طبقة الاستقراء ١٦ عدسة بحث، و٨٨ مفهومًا مرشحًا، و٦٤ دعوى أولية. الاستقراء الدلالي الشامل قيد الاستكمال؛ هذه النسخة لا تدعي اكتماله.

- الملف التفاعلي: [`index.html`](index.html). يمكن تنزيله وفتحه بمتصفح حديث دون اتصال.
- يعتمد التحليل على النص المرفق وحده. لم تُستخدم تفاسير أو معاجم أو مصادر دينية أو تاريخية خارجية.
- كل دعوى في الأداة مرتبطة بشواهدها وحدودها ودرجة يقين وصفية.
- التلازم اللفظي ومركزية الشبكة لا يثبتان وحدهما المعنى أو السببية.
- بيانات اشتقاق المرفق تتضمن تنبيهًا حول الموضعين ٩٥:١ و٩٧:١؛ النص محفوظ كما ورد، والتنبيه ظاهر في الأداة.

مصدر النص بحسب بيانات المرفق: [Tanzil Project](https://tanzil.net)، بترخيص [Creative Commons Attribution 3.0](https://tanzil.net/docs/Text_License). نص الحقوق محفوظ في الأداة وفي [`NOTICE.txt`](NOTICE.txt). لم يُعدّل نص الآيات.

نشر الملف في مستودع عام لا يُعد اعتمادًا نهائيًا للعرض أو المعاني. بصمة الملف المنشور محفوظة في [`SHA256SUMS`](SHA256SUMS).
